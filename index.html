Antes de começar

Condição, comparação e lógica booleana

Uma condição é uma expressão que resulta em apenas dois valores: True (verdadeiro) ou False (falso).

Operadores relacionais

== igual · != diferente
> maior · < menor
>= maior ou igual · <= menor ou igual

Operadores lógicos

and: todas as condições verdadeiras
or: pelo menos uma verdadeira
not: inverte o resultado lógico

idade = 20
tem_documento = True

print(idade >= 18)                 # True
print(idade >= 18 and tem_documento) # True
Atenção: = atribui um valor; == compara dois valores.
3.1 · Decisão simples

Estrutura condicional if

A decisão simples executa um bloco somente quando a condição é verdadeira. Se for falsa, o bloco é ignorado.

if condição:
    comando
    outro_comando

Exemplo: verificar maioridade

idade = int(input("Digite sua idade: "))

if idade >= 18:
    print("Maior de idade")

print("Fim do programa")
A indentação define quais instruções pertencem ao bloco do if. Em Python, use normalmente 4 espaços.
3.1 · Decisão simples

Entendendo o fluxo

Condição verdadeira

Entrada: idade = 22

idade >= 18 → True

Saída: “Maior de idade” e “Fim do programa”.

Condição falsa

Entrada: idade = 16

idade >= 18 → False

Saída: somente “Fim do programa”.

Quando utilizar?

  • Validar uma condição antes de executar uma ação.
  • Verificar se há saldo suficiente.
  • Identificar se uma nota atingiu uma pontuação mínima.
3.1 · Decisão composta

if e else

A decisão composta oferece dois caminhos: um quando a condição é verdadeira e outro quando é falsa.

if condição:
    comandos_se_verdadeiro
else:
    comandos_se_falso

Exemplo: aprovado ou reprovado

nota = float(input("Informe a nota: "))

if nota >= 7:
    print("Aprovado")
else:
    print("Reprovado")

Se a nota for 8.5, o programa exibe “Aprovado”. Se for 5.0, exibe “Reprovado”.

3.1 · Decisão composta

Mais de uma condição: operadores lógicos

É possível combinar condições para representar regras mais completas.

idade = int(input("Idade: "))
matriculado = input("Está matriculado? (s/n): ")

if idade >= 18 and matriculado == "s":
    print("Acesso autorizado")
else:
    print("Acesso não autorizado")
and

As duas condições precisam ser verdadeiras.

or

Basta uma das condições ser verdadeira.

Dica: escreva a regra em português antes de traduzi-la para código. Isso reduz erros de lógica.
3.2 · Decisão aninhada

Uma decisão dentro de outra

Uma estrutura aninhada ocorre quando um if, elif ou else contém outra estrutura de decisão.

Exemplo: classificação de nota

nota = float(input("Nota (0 a 10): "))

if nota >= 7:
    if nota >= 9:
        print("Aprovado com excelente desempenho")
    else:
        print("Aprovado")
else:
    print("Reprovado")

Primeiro, o programa verifica se a nota é suficiente para aprovação. Se for, faz uma segunda análise.

A indentação evidencia o nível de cada decisão. Uma decisão interna só é avaliada quando o fluxo alcança aquele bloco.
3.2 · Múltipla escolha

Usando if, elif e else

Quando existem várias alternativas, elif permite testar condições em sequência. O primeiro bloco verdadeiro é executado.

nota = float(input("Informe a nota: "))

if nota >= 9:
    conceito = "A"
elif nota >= 7:
    conceito = "B"
elif nota >= 5:
    conceito = "C"
else:
    conceito = "D"

print("Conceito:", conceito)
A ordem importa! Comece pelas faixas mais altas. Depois que uma condição é atendida, as seguintes não são verificadas.
3.2 · Múltipla escolha

Menu de opções

Uma aplicação comum é criar menus que direcionam o usuário para diferentes operações.

print("1 - Cadastrar")
print("2 - Consultar")
print("3 - Sair")
opcao = input("Escolha: ")

if opcao == "1":
    print("Cadastro selecionado")
elif opcao == "2":
    print("Consulta selecionada")
elif opcao == "3":
    print("Encerrando...")
else:
    print("Opção inválida")

Observe que input() retorna texto. Por isso, as opções foram comparadas com strings como "1".

3.2 · Comparando estruturas

Qual estrutura escolher?

if

Uma condição independente. Ex.: mostrar um alerta se o estoque estiver baixo.

if / else

Dois caminhos mutuamente exclusivos. Ex.: aprovado ou reprovado.

Aninhada

Uma decisão depende de outra. Ex.: verificar categoria e, depois, uma regra específica.

if / elif / else

Várias alternativas em sequência. Ex.: conceito A, B, C ou D.

3.3 · Repetição com variável de controle

Laço for

O for é indicado quando percorremos uma sequência ou sabemos quantas repetições desejamos executar.

for variavel in sequencia:
    comandos

Exemplo: imprimir de 1 a 5

for numero in range(1, 6):
    print(numero)

Saída: 1, 2, 3, 4, 5. O limite final do range() não é incluído.

A variável numero recebe um valor diferente a cada passagem pelo laço.
3.3 · Entendendo range()

Como funciona o range()?

range(5)

Gera 0, 1, 2, 3, 4.

range(1, 6)

Gera 1, 2, 3, 4, 5.

range(0, 10, 2)

Gera 0, 2, 4, 6, 8.

range(10, 0, -1)

Gera 10 até 1, em ordem decrescente.

# Tabuada do 7
for i in range(1, 11):
    print(f"7 x {i} = {7 * i}")
3.3 · Aplicação prática

Somatório de valores

Uma variável acumuladora guarda o resultado parcial ao longo das repetições.

soma = 0

for contador in range(1, 6):
    valor = float(input(f"Digite o {contador}º valor: "))
    soma = soma + valor

print("Soma:", soma)
print("Média:", soma / 5)

Conceitos importantes

  • Contador: controla ou identifica as repetições.
  • Acumulador: guarda um total que é atualizado a cada ciclo.
  • Inicialização: atribui o valor inicial antes do laço.
Neste exemplo, o laço executa exatamente cinco vezes.
3.4 · Teste no início

Laço while

O while repete um bloco enquanto a condição for verdadeira. A condição é testada antes de cada execução.

while condição:
    comandos

Exemplo: contagem

contador = 1

while contador <= 5:
    print(contador)
    contador = contador + 1

O programa imprime de 1 a 5. Quando o contador chega a 6, a condição fica falsa e o laço termina.

Atualizar a variável de controle é essencial quando ela participa da condição do while.
3.4 · Teste no início

Validação de entrada com while

O while é útil quando não sabemos previamente quantas tentativas serão necessárias.

senha = input("Crie uma senha com 6 caracteres: ")

while len(senha) < 6:
    print("Senha muito curta. Tente novamente.")
    senha = input("Digite outra senha: ")

print("Senha cadastrada!")

Outro exemplo: repetir até uma opção válida

opcao = ""

while opcao != "s" and opcao != "n":
    opcao = input("Continuar? (s/n): ").lower()

print("Resposta registrada:", opcao)
3.3 × 3.4 · Comparação

for ou while?

for

  • Quantidade conhecida ou sequência definida.
  • Itera sobre itens de uma coleção ou intervalo.
  • Ex.: calcular a média de 30 alunos.

while

  • Repetição depende de uma condição.
  • Quantidade de ciclos pode ser desconhecida.
  • Ex.: solicitar senha até ser válida.
Ambos podem resolver alguns mesmos problemas. A escolha deve priorizar clareza, segurança e adequação à lógica.
Cuidados importantes

Erros comuns em estruturas de repetição

  • Loop infinito: a condição do while nunca se torna falsa.
  • Off-by-one: errar o início ou o limite do range().
  • Variável não inicializada: usar contador ou acumulador antes de atribuir um valor.
  • Indentação incorreta: colocar uma instrução fora ou dentro do bloco errado.
  • Condição inadequada: usar and quando a regra exige or, ou vice-versa.
# Exemplo de loop infinito (não execute assim!)
contador = 1
while contador <= 5:
    print(contador)
    # faltou incrementar contador

Exercício 1 · Decisão

Enunciado: solicite a idade de uma pessoa. Se ela tiver menos de 16 anos, informe “Não pode votar”. Entre 16 e 17 ou acima de 70, informe “Voto facultativo”. Nos demais casos, informe “Voto obrigatório”.

Implemente usando if / elif / else.

idade = int(input("Idade: "))

if idade < 16:
    print("Não pode votar")
elif idade < 18 or idade > 70:
    print("Voto facultativo")
else:
    print("Voto obrigatório")
Observação: a regra considera voto facultativo também para maiores de 70 anos.

Exercício 2 · Repetição for

Enunciado: desenvolva um programa que leia 10 números e apresente ao final quantos são positivos, quantos são negativos e quantos são iguais a zero. 
positivos = 0
negativos = 0
zeros = 0

for i in range(10):
    numero = float(input("Digite um número: "))
    if numero > 0:
        positivos += 1
    elif numero < 0:
        negativos += 1
    else:
        zeros += 1

print("Positivos:", positivos)
print("Negativos:", negativos)
print("Zeros:", zeros)

Exercício 3 · Repetição while

Enunciado: faça um programa que solicite números inteiros ao usuário até que ele digite 0. Ao final, mostre a soma dos números informados, sem incluir o zero. 
soma = 0
numero = int(input("Digite um número (0 encerra): "))

while numero != 0:
    soma += numero
    numero = int(input("Digite outro número (0 encerra): "))

print("Soma:", soma)
O teste ocorre antes de cada repetição. Se o primeiro valor for 0, o laço não executa.

Sistema de notas da turma

Desenvolva um programa que:

  1. Leia a quantidade de alunos.
  2. Para cada aluno, leia nome e nota de 0 a 10.
  3. Valide a nota: se estiver fora do intervalo, solicite novamente.
  4. Classifique: aprovado (nota ≥ 7), recuperação (5 ≤ nota < 7) ou reprovado (nota < 5).
  5. Ao final, apresente a quantidade em cada situação e a média geral.
Requisitos: use for para percorrer os alunos, while para validar a nota e if / elif / else para classificar.
